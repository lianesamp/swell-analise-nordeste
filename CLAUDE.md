# About me
- I'm a full-stack developer (React, TypeScript, Laravel) building a portfolio for jobs in Spain.
- I use these projects to LEARN. I'd rather understand than go fast.

# How to work with me
- Before coding a feature, show a short plan and wait for my OK.
- Work in small steps. At the end of each step, stop and summarize what you did.
- Explain every new concept, library or pattern the first time it appears
  (what it is, why it was chosen, a common alternative). Use plain English.
- When I already know something from another stack (Laravel, Vue), compare with it.
- At the end of each step, add new terms to LEARNING.md (term + 1-2 line explanation).
- Don't install dependencies without saying which one and why.
- Always follow the docs for the current version of each library; tell me if something changed recently.

# Code standards
- Strict TypeScript, no `any`.
- Code, names and comments in English.
- Small, testable components; business logic outside components.
- Validate input with Zod (or the framework's equivalent).
- Never put secrets in code; use .env and keep a .env.example.

# Git and GitHub
- Small commits with Conventional Commits (feat:, fix:, test:, docs:, chore:).
- Suggest a commit at the end of each step; don't push unless I ask.
- README in English with: description, screenshot, deploy link, stack, how to run, tests and "What I learned".
